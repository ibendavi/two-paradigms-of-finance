Multi-Source Embedding Analysis: Methodology

Overview

The embedding-based paradigm analysis measures how financial discourse has shifted between two poles: pre-1920 practitioner thinking and post-2000 academic thinking. Version 4 extends the analysis from periodicals alone to three source types: periodicals, textbooks, and earnings call transcripts.

The core insight is that these three sources capture different aspects of financial knowledge:

  • Periodicals — what was being reported and discussed in real time (the baseline)
  • Textbooks — what was being taught and codified as formal theory
  • Earnings calls — what practitioners actually say when making financial decisions

The Three Source Types

1. Periodicals (the baseline)

Files: Periodicals/Practitioner/*/YYYY/*.txt and Periodicals/Academic/*/articles_*.jsonl

  • ~255 Archive.org SIM collections (practitioner magazines, trade journals, Fed publications)
  • ~43 academic journals (via CrossRef/OpenAlex/Semantic Scholar APIs)
  • Time range: 1839 (Hunt's Merchants Magazine) to present
  • ~159,000 unique academic articles with ~93,000 abstracts

Practitioner periodicals use full-text OCR (_djvu.txt) files downloaded from Archive.org. Academic journals use title + abstract text from CrossRef/OpenAlex APIs.

Role: Provides the two poles for scoring. Practitioner periodicals 1860-1919 define the "pre-MM practitioner" pole; academic journals 2000-2025 define the "modern academic" pole.

2. Textbooks (teaching what gets taught)

Files: Textbooks/Academic/**/*.pdf and Textbooks/Practitioner/**/*.pdf

  • ~2,600+ PDFs organized by stream (Academic/Practitioner) and topic
  • Text extracted via pdftotext, cached to Periodicals/textbook_text_cache/ (MD5-keyed)
  • Year extracted from filename: Author - Title (Book YYYY).pdf
  • Max 200,000 segments per run (configurable via --max-textbooks)

Role: Shows what was being formally taught. Textbooks reveal when paradigm shifts were codified in the curriculum. The pre-MM / post-MM transition (1958) should appear most cleanly here — practitioners kept writing EPS-focused books while academic textbooks pivoted to NPV/CAPM frameworks after Modigliani-Miller.

Expected finding: Academic textbooks should show a sharp shift toward the academic pole after 1958-1965. Practitioner textbooks should stay closer to the practitioner pole throughout, diverging from academic textbooks post-1960.

3. Earnings Calls (what managers actually say)

Files: D:/data/earnings_calls/transcripts_YYYY.jsonl

  • 540,349 transcripts (47 GB), earnings calls from public companies
  • Sampled at 1-in-10 rate (EARNINGS_SAMPLE_RATE = 10), stratified by year
  • Up to 3 segments per transcript (first 30,000 chars), max 100,000 segments total
  • All tagged as stream = "practitioner" (they are by definition practitioner content)

Role: Ground truth for modern practitioner discourse. If managers are EPS maximizers in practice, their earnings call language should cluster near the practitioner pole even in the modern era — diverging from academic discourse (which moved to NPV/CAPM).

Expected finding: Earnings calls should score persistently positive (near practitioner pole) across all time periods, especially for EPS and valuation topics.

Pole Computation

Always and only from periodicals. Textbooks and earnings calls do NOT contribute to pole computation, even when they are included in scoring.

Practitioner pole = centroid of periodical segments where:
    stream == "practitioner" AND year in [1860, 1919]

Academic pole = centroid of periodical segments where:
    stream == "academic" AND year in [2000, 2025]

Both centroids are L2-normalized before scoring.

This design ensures poles are stable across runs and comparable across source types: you can run textbooks-only and still get scores on the same scale as periodicals-only.

Scoring

For each segment s:

score(s) = cosim(embed(s), prac_pole) - cosim(embed(s), acad_pole)
  • score > 0: closer to the pre-1920 practitioner paradigm (earnings capitalization, yield-based pricing, EPS focus, comps-based valuation)
  • score < 0: closer to the post-2000 academic paradigm (NPV/DCF, CAPM, factor models, efficient markets, option pricing)
  • score = 0: equidistant — "bridge" content

The model is all-MiniLM-L6-v2 (384-dim sentence embeddings), loaded via sentence_transformers. Segments are truncated to 1,500 chars for embedding.

Topic Filters

7 topics are tracked. Each topic uses method-neutral keyword filters — keywords identify the SUBJECT but deliberately exclude method terms (NPV, DCF, CAPM, earnings yield, P/E ratio). This ensures the paradigm signal comes from the embedding (HOW people discuss the topic), not from keyword presence.

Running the Analysis

Full run (all sources, all topics)

cd "E:/Dropbox/Research1/EPS Literature/Periodicals"
python analyze_embeddings_v4.py

Takes approximately 90 minutes for all 7 topics × 3 sources.

Specific source types

# Textbooks only
python analyze_embeddings_v4.py --sources textbooks

# Earnings calls only
python analyze_embeddings_v4.py --sources earnings_calls

# Periodicals + textbooks (no earnings calls)
python analyze_embeddings_v4.py --sources periodicals textbooks

Specific topics

python analyze_embeddings_v4.py --sources textbooks --topics valuation earnings capstruct

python analyze_embeddings_v4.py --sources earnings_calls --topics earnings valuation

Force re-run (ignore cached embeddings)

python analyze_embeddings_v4.py --force valuation

Limit segment counts

python analyze_embeddings_v4.py --max-textbooks 50000 --max-earnings 30000

Prerequisite: Textbook Text Extraction (Task #32/#39)

Before running v4 for textbooks, pre-extract all PDF text:

python Periodicals/pre_extract_textbooks.py

This populates Periodicals/textbook_text_cache/ and avoids re-extracting on each run. Estimated time: 2-4 hours for ~2,600 PDFs.

Interpreting Results

In trajectories.json

The output adds source_type_histograms to each topic entry:

{
  "topic": "earnings",
  "source_type_histograms": {
    "periodicals": { ... },
    "textbooks":   { ... },
    "earnings_calls": { ... }
  }
}

Each histogram gives the score distribution by time window (decade or 20-year period).

What to look for

The pre-MM / post-MM shift in textbooks: Academic textbooks from before 1958 should score positively (practitioner pole). After 1965-1970, academic textbooks should score negatively (academic pole). Practitioner textbooks should remain positive throughout.

Earnings calls as practitioner anchor: Earnings calls should score strongly positive for EPS/earnings topics. For valuation topics, they should also be positive (managers use comps, not DCF).

Convergence vs. divergence by era: Pre-1920: periodicals + (few) textbooks tightly clustered near practitioner pole. 1920-1960: slow divergence begins as academic journals formalize theory. 1960-2000: sharp divergence; academic stream moves rapidly toward academic pole. Post-2000: three streams visible — earnings calls (prac), academic journals (acad), practitioner magazines (declining, mixed).

Connection to Discriminative Terms Analysis

The discriminative terms analysis (analyze_discriminative_terms.py) identifies WHICH specific words and phrases drive the paradigm scores — answering "what exactly changed?"

For example, if the embedding analysis shows academic textbooks diverged from practitioner textbooks after 1960, the discriminative terms analysis should show that words like "discount rate", "NPV", "beta", "CAPM" became more frequent in academic textbooks while "earnings yield", "capitalization rate", "P/E multiple", "earnings per share" declined.

The two analyses are complementary:

  • Embedding analysis: captures holistic paradigm distance (how similar overall)
  • Discriminative terms: pinpoints specific vocabulary shifts (which concepts changed)

Both should be run and their findings should corroborate each other. The discriminative terms are more interpretable for writing papers; the embeddings are more rigorous for measuring continuous change over time.
